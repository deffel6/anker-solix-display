⚡ Anker Solix Display

Firmware direkt aus dem Browser auf den ESP32-C3 spielen.

Funktioniert nur in Chrome oder Edge auf dem Rechner. Firefox und Safari unterstützen den seriellen Zugriff im Browser nicht, und auf Mobilgeräten geht es ebenfalls nicht.
Dieser Browser kann das nicht — bitte Chrome oder Edge verwenden. Nur über HTTPS oder localhost möglich.

Danach einrichten

  1. Der ESP32 spannt ein WLAN namens Anker-Display-Setup auf.
  2. Damit verbinden und im Browser 192.168.4.1 aufrufen.
  3. WLAN-Zugang und Anker-Konto eintragen, speichern.
  4. Nach dem Neustart zeigt das Display eine IP-Adresse — die im Heimnetz aufrufen und die Anlage auswählen.

Angezeigte Werte

Solarleistungalle 3 s
Akkustandalle 3 s
Akkuleistung mit Richtungalle 3 s
Netzbezug / Einspeisungalle 3 s

SpeicherSolarbank 3 Pro E2700 (A17C5)
Solarbank-Firmwarev1.0.7.3
NetzzählerShelly EM3 (SHEM3)
Abhängig vom Firmwarestand der Solarbank. Anker veröffentlicht die hier genutzte Schnittstelle nicht und versioniert sie nicht. Die Zuordnung der Messwerte wurde an einer Solarbank mit Firmware v1.0.7.3 ermittelt — ein Update des Speichers kann sie ohne Ankündigung verschieben. Zeigt die Anzeige danach unsinnige Werte, liegt es vermutlich daran und nicht am Display. Wie man das nachweist
